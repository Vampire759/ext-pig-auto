# pig-auto 自动管家

> **这是桌面小猪 dsh-piggy 的扩展插件**，不是独立程序。
> 项目地址：https://github.com/CLICGGER-TYPES/dsh-piggy

## 功能

- 🐷 **离线自动照顾**：小猪在你不在的时候自动学习、进食、洗澡、玩耍、赚钱，回来一键领取，离线最长补 72 小时。
- 📚 **五学段 24 科**：🎒小学 → 🏫中学 → 🎓大学 → 🧑‍🔬研究生 → ♾️学无止境，学完本学段全部科目自动升入下一学段；学无止境循环深造不封顶。
- 🧠 **学过判断**：面板有课程表，已学过/在学/未学的科目一目了然。
- 💼 **学习/赚钱双开关**：可以同时开启兼顾学习和赚钱；只开赚钱就去已解锁的最高价值工作（搬砖→收银→厨师→程序员→科学家→CEO 等 10 种，按学段解锁）；只开学习就专心学习。
- 💾 **存档导出/导入**：复制导出串，换电脑/重装游戏后导入即可继续。
- ↩️ **返回按钮**：面板模式保留宿主画的「‹ 返回」栏；大界面（小窗口）模式自绘「‹ 返回」。

## 安装

1. 下载 `dist/ext-pig-auto-1.3.2.piggyext`
2. 游戏面板 → 设置 → 扩展 → 导入本地扩展，选择该文件
3. 需要 dsh-piggy **v0.35.0 及以上**（v0.37.1 已验证）

## 文件结构

```
manifest.json   # 扩展声明（key/version/minGame/钱包）
server.js       # 服务端逻辑（离线结算/学段/工作/导出导入）
client.js       # 面板界面（状态/开关/课程表/导出导入/返回按钮）
pig-auto.test.js# 22 个测试用例
dist/           # 打包好的安装包
```

## 数值设定（v1.3.2）

| 项目 | 设定 |
|---|---|
| 结算周期 | 5 分钟/轮，最多 864 轮（72 小时） |
| 学习 | 每科 2 小时，学段效率 1.0/1.2/1.4/1.6/2.0 |
| 自理 | 进食 24 轮/次（20 币）、洗澡 36 轮/次（15 币）、玩耍 18 轮/次（10 币） |
| 赚钱 | 时薪 = 10 × 学段效率，学无止境每轮 +0.1 不封顶 |
| 钱包 | 管家币 🪙（rate 0.5，不可购买） |
